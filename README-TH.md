# MyHealthCare v2

เวอร์ชันปรับปรุงจากโปรเจกต์เดิม โดยเน้นป้องกันข้อมูลสูญหายก่อนย้ายขึ้นฐานข้อมูลออนไลน์

## เพิ่มแล้วในเวอร์ชันนี้

- ดาวน์โหลดและนำเข้าไฟล์สำรองข้อมูลเดิมจากหน้า “ข้อมูลส่วนตัว”
- เมนูยา: ชื่อยา ขนาดยา วิธีรับประทาน ช่วงอาหาร วันที่เริ่ม แพทย์ โรงพยาบาล และเหตุผลที่ใช้ยา
- บันทึก “รับประทานแล้ว / ข้ามครั้งนี้ / หยุดยาแล้ว” แยกตามสมาชิก
- นำระบบสุ่มค่าผลแลปออก เพื่อไม่ให้แสดงข้อมูลสุขภาพที่ไม่ได้อ่านจากเอกสารจริง
- แก้ TypeScript error และยืนยันว่า production build ผ่าน
- เตรียม migration สำหรับบัญชีสมาชิกครอบครัว ผลแลป ไฟล์ต้นฉบับ ยา และ LINE โดยใช้ RLS

## สำคัญก่อนเปลี่ยนเว็บออนไลน์

1. เปิดเว็บเดิมจากเครื่องและเบราว์เซอร์ที่มีข้อมูล
2. ไปที่ “ข้อมูลส่วนตัว” แล้วกด “ดาวน์โหลดไฟล์สำรอง”
3. เก็บไฟล์ JSON ไว้จนกว่าจะตรวจว่าข้อมูลย้ายเข้าฐานข้อมูลครบ
4. ห้ามใช้ migration กับฐานข้อมูลจริงก่อนสำรองฐานข้อมูลเดิม

การอ่านผลแลปด้วย AI และการส่ง LINE ต้องทำผ่านฟังก์ชันฝั่งเซิร์ฟเวอร์ เพื่อไม่ให้กุญแจลับปรากฏในเว็บเบราว์เซอร์ และทุกค่าที่ AI อ่านต้องให้ผู้ใช้ยืนยันก่อนบันทึก
